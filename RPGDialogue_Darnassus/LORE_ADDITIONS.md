**Not used (and why):** "Tyrande teaches that the Holy Light and the Light of Elune are closely related" and "the Church sent members to the Sisterhood to lead them to the Light" both come from Season of Discovery quests (Meditation on Elune, Meditation on the Light (human)). So no NPC states how the two faiths relate; Tyrande and A'moora say what they've seen and leave it open. Crown of the Earth (7)/(8) (Forever, Fandral to Tyrande) and Exploring the Alliance (Forever) have no wiki pages yet, so they aren't referenced. Doling Justice (2) shares its title with part 1, so it isn't used as a condition.

**Year 1 notes:** no Valstann, no morrowgrain, no Nightmare, nothing that hints at Fandral's fall (his pride and his burden only). No wedding: Tyrande says "Malfurion".

## World-pack additions (ready to paste into RPGDialogue_World/topics.lua)

NPCs in Darnassus, Teldrassil, Darkshore and Ashenvale already answer these topics in their `topics` tables; they only become askable once the topics exist. `learn` effects for them were left out so the validator stays quiet.

```lua
P:Topic { id = "teldrassil", keywords = { "Teldrassil" }, name = "Teldrassil", category = "places", learned = "Tenaron, Corithras or Fandral" }
P:Topic { id = "malfurion", keywords = { "Malfurion" }, name = "Malfurion Stormrage", category = "people", learned = "Tyrande or Fandral in Darnassus" }
P:Topic { id = "sisterhood_of_elune", keywords = { "Sisterhood" }, name = "The Sisterhood of Elune", category = "people", learned = "Tyrande, A'moora or Gwennyth" }
P:Topic { id = "sentinels", keywords = { "Sentinels" }, name = "The Sentinels", category = "people", learned = "Tyrande, or any Sentinel" }
P:Topic { id = "warsong", keywords = { "Warsong" }, name = "The Warsong in Ashenvale", category = "threats", learned = "Tyrande, Raene or Splintertree Post" }
P:Topic { id = "silithid", keywords = { "silithid" }, name = "The silithid", category = "threats", learned = "Gracina Spiritmight in Darnassus" }
P:Topic { id = "fel_moss", keywords = { "Fel Moss" }, name = "Fel Moss", category = "threats", learned = "Melithar, Athridas, Terenthis or Thundris" }
P:Topic { id = "furbolgs", keywords = { "furbolg" }, name = "The furbolgs", category = "threats", learned = "Athridas, Thundris or Raene" }
P:Topic { id = "dark_strand", keywords = { "Dark Strand" }, name = "The Dark Strand", category = "threats", learned = "Delgren the Purifier at Maestra's Post" }
```

Who answers what: teldrassil (Tyrande, Fandral `next=tree`, Tenaron, Corithras), malfurion (Tyrande `next=malfurion`, Fandral), sisterhood_of_elune (Tyrande, A'moora, Gwennyth), sentinels (Tyrande), warsong (Tyrande `next=ashenvale`, Raene, Senani, Mastok), silithid (Gracina `next=silithid`), fel_moss (Melithar, Athridas, Terenthis `next=moss`, Thundris), furbolgs (Athridas, Terenthis, Thundris, Raene `next=furbolgs`), dark_strand (Delgren `next=strand`).
